## Getting Started

### First Launch

When you first open FlashForge, you'll see:
1. A welcome screen with an empty project list
2. A "New Set" button to create your first flashcard set
3. A demo set will be automatically created to help you explore features

### Quick 5-Minute Workflow

1. Click **"New Set"**
2. Enter a title (e.g., "Spanish Verbs")
3. Click **"Add Card"** and enter front/back text
4. Repeat for 10-20 cards
5. Click **"Preview"** to see how they'll print
6. Click **"Print"** and save as PDF

## Creating Flashcard Sets

### Set Metadata

Each set can include:
- **Title** (required): The name of your flashcard set
- **Subtitle** (optional): Additional context (e.g., "Unit 3 - Verbs")
- **Class Name** (optional): Which class this is for (e.g., "Spanish 101")
- **Notes** (optional): Private notes for yourself

### Card Types

**Single-Sided Cards**
- All content on one side
- Best for: word lists, character recognition, picture cards
- Use cases: vocabulary walls, matching games, student sorting activities

**Double-Sided Cards**
- Content on both front and back
- Best for: self-study, quiz cards, translation practice
- Use cases: flip-and-check studying, classroom games, homework

## Adding Cards

### Manual Entry

Click **"Add Card"** to create a new blank card, then fill in:
- **Front Text**: The prompt or question
- **Back Text**: The answer or translation
- **Front Secondary** (optional): Additional info (e.g., pronunciation)
- **Back Secondary** (optional): Example sentence, notes
- **Image**: Upload a picture (click the image icon)

### Image Upload

Supported formats: JPG, PNG, GIF, WebP

**Tips for good images:**
- Use at least 800x800px for quality
- Square images work best
- Photos will be automatically compressed to save storage
- Maximum ~5MB per image recommended

### Editing Cards

- Click any card to open the editor
- Changes save automatically
- Use the "Delete Card" button to remove unwanted cards
- Future: Drag to reorder cards

## Print Settings

### Layout Options

**Cards Per Page**
- 1 per page: Large flashcards (5.5" x 8.5" on letter)
- 2 per page: Half-page cards (8.5" x 5.5")
- 4 per page: Quarter-page cards (4.25" x 5.5")
- 6 per page: Sixth-page cards (2.75" x 4.25")
- 8 per page: Playing card size (2.125" x 3.375")
- 9 per page: Business card size (2.5" x 2.83")
- 10 per page: Mini cards (2.125" x 2.2")
- 12 per page: Small flashcards (2.125" x 1.833")

**Paper Size**
- **US Letter**: 8.5" × 11" (standard in North America)
- **A4**: 210mm × 297mm (standard in most other countries)

**Orientation**
- **Portrait**: Tall orientation (recommended for most uses)
- **Landscape**: Wide orientation (good for large text cards)

### Styling Options

**Themes**
- **Minimal**: Clean white background, simple and professional
- **Classroom Cute**: Warm amber background, friendly feel
- **Bold Vocabulary**: Gradient background, eye-catching
- **Picture Focus**: Subtle gray, emphasizes images
- **Ink Saver**: High contrast black/white, printer-friendly
- **Quiz Card**: Slate background, serious study vibe

**Visual Options**
- **Show Borders**: Add a border around each card
- **Show Cut Lines**: Dashed lines to guide cutting
- **Show Rounded Corners**: Soften card edges
- **Show Numbering**: Add card numbers (helpful for ordering)
- **Show Set Title**: Display set name on each card

### Font & Color

**Font Family**
- Inter (default): Clean, highly readable
- Space Grotesk: Geometric, modern
- JetBrains Mono: Monospace, technical look

**Font Size**: 10px - 32px (auto-scales based on layout)

**Colors**
- Main Color: Primary text color
- Accent Color: Secondary text and highlights

## Printing & PDF Export

### Method 1: Save as PDF (Recommended)

1. Click the **"Print"** button in FlashForge
2. Your browser's print dialog will open
3. Select **"Save as PDF"** or **"Microsoft Print to PDF"**
4. Set margins to **"None"** or **"Minimum"**
5. Ensure scale is **100%** or **"Actual Size"**
6. Click **"Save"** and choose a filename

**Why this method?**
- ✅ Produces crisp, vector text (not blurry)
- ✅ Consistent across all computers
- ✅ Works offline
- ✅ No file size limits
- ✅ No external services needed

### Method 2: Direct Printing

1. Click **"Print"**
2. Select your printer
3. Set margins to minimum
4. Verify preview looks correct
5. Print

### Double-Sided Printing

**Step 1: Print Fronts**
1. Preview shows the front pages first
2. Print just the front pages

**Step 2: Flip Paper**
- **Long-Edge Flip**: Most common, flip along the long side
- **Short-Edge Flip**: Less common, flip along the short side
- Test with ONE sheet first to see which way your printer flips

**Step 3: Print Backs**
1. Re-insert the printed pages
2. Print the back pages
3. Pages should align perfectly

**If alignment is off:**
- Check that scale is 100%
- Verify margins are identical for front and back
- Some printers have slight offsets - this is normal
- Cut with extra margin and trim cards individually if needed

### Cutting Your Cards

**With a Paper Cutter**
1. Print your PDF
2. Use the cut lines as guides
3. Cut columns first, then rows
4. Stack and cut multiple sheets at once for speed

**With Scissors**
1. Cut along the cut lines
2. Round corners if desired (corner rounder punch)
3. Use a ruler for straight edges

**Laminating** (optional)
1. Cut cards slightly larger than final size
2. Laminate
3. Cut to final size (leaves sealed edge)

## Tips & Best Practices

### For Vocabulary Cards

- Keep front text to 1-3 words
- Use secondary text for pronunciation or part of speech
- Include an image when possible (boosts retention)
- Stick to one language pair per set

### For Quiz Cards

- Front = question, Back = answer
- Keep questions concise
- Number the cards if you want them in order
- Consider color-coding by difficulty

### For Picture Cards

- Use high-quality, clear images
- Choose images that represent the concept unambiguously
- Avoid cluttered or busy backgrounds
- Crop images before uploading for best results

### Storage Tips

- Browser storage is limited to ~5-10MB total
- Each set with 20 cards + images ≈ 500KB - 2MB
- You can store dozens of sets comfortably
- Export sets as JSON to back up or clear space
- Delete unused demo sets

### Classroom Tips

- Print extra copies (students lose them!)
- Laminate frequently-used sets
- Use cardstock for durability
- Color-code by unit or difficulty
- Store in labeled envelopes or boxes

## Data Management

### Local Storage

All data is stored in your browser's localStorage:
- Persists between sessions
- Private to your browser/device
- Not synced across devices
- Not accessible from other browsers on same computer

### Exporting Sets

*JSON export coming in future update*

To manually backup:
1. Open browser DevTools (F12)
2. Go to Application → Local Storage
3. Find `flashforge_sets`
4. Copy the value
5. Save to a text file

### Importing Sets

*CSV import coming in future update*

### Clearing Data

To start fresh:
1. Open browser DevTools (F12)
2. Go to Application → Local Storage
3. Right-click `flashforge_sets` → Delete

Or use your browser's "Clear browsing data" feature (select "Cookies and site data").

## Troubleshooting

### Common Issues

**Cards are cut off when printing**
- Set margins to "None" or "Minimum" in print dialog
- Ensure scale is 100%
- Try a different browser (Chrome recommended)
- Your printer may have non-printable margins

**Images are blurry**
- Use larger source images (800px+ recommended)
- Make sure you're using "Save as PDF", not screenshot tools
- Check that scale is 100% in print dialog

**Text is too small**
- Use fewer cards per page
- Increase font size in settings
- Keep text shorter

**App won't save my changes**
- Check that JavaScript is enabled
- Ensure you have storage space available
- Clear browser cache and try again
- Check browser console for errors

**Lost my flashcard sets**
- Data is stored per-domain, use the exact same URL
- Check you're using the same browser
- localStorage may have been cleared by browser cleaning tools
- Future updates will add export/backup features

## AI Flashcard Agent (BYOK)

### Overview

The **Flashcard Agent** creates full decks with text and real web images. It runs in two decoupled phases so the UI stays responsive, shows live progress, and can be cancelled at any time.

### Usage

1. Open any set (or create a new empty one)
2. Click **Flashcard Agent** in the editor toolbar
3. Accept the image-use responsibility notice
4. Choose **Create new cards** (empty set) or **Enhance current cards**
5. Enter your AI credentials (model, base URL, API key) — see README for supported providers
6. Open **Image Search Settings** to configure at least one image provider
7. Click **Run Flashcard Agent**

### Progress & Cancel

- A progress bar shows Phase 1 ("Generating text… X/Y") then Phase 2 ("Searching images… X/Y")
- Click **Cancel** at any time to stop; cards and images already fetched are preserved
- Cards appear in the set immediately after Phase 1, before images are attached

### Image Search Settings

Open via the **Image Search Settings** button in the agent dialog or web image search dialog. From there you can:

- Choose provider: **Auto** (recommended), Brave, Pixabay, Pexels, Google, or Openverse
- Enter per-provider API keys (stored in localStorage, never sent anywhere else)
- See **"Server configured ✓"** badges if an admin has configured keys via environment variables

**Openverse requires no key** and is always available as a Creative Commons fallback. Auto mode tries all configured providers in priority order.

### Web Image Search

The **Search Web Images** dialog (accessible from the image icon on any card) also uses the provider registry. Click **Settings** in that dialog to open Image Search Settings. If no results appear, try a different keyword or add a provider key.

### Image Embedding

Images are embedded (downloaded + stored as base-64 data URLs) by default so printed PDFs never show broken images. They are compressed to ≤ 1000 px / JPEG 0.75 client-side. Uncheck "Download/embed images" in the agent options to store hotlink URLs instead (smaller storage, but URLs may expire).

### Error Handling

- **Auth failure** (401/403): check your AI API key and base URL
- **Rate limit** (429): the agent retries once automatically with backoff; if it persists, wait and retry
- **No images found**: the card is still created without an image; configure a provider with a key for better coverage
- **Timeout**: text-generation batches time out after 55 s; reduce deck size or switch to a faster model
